# 📊 Interactive Sales Dashboard

## Week 6 — Data Visualization Mastery with Seaborn & Plotly

---

## 📌 Project Overview

The **Interactive Sales Dashboard** is a data visualization project developed as part of Week 6 of the Data Science Internship at The Developers Arena.

The project analyzes a sales dataset containing information about products, quantities, prices, customers, regions, dates, and total sales.

The main objective is to transform raw sales data into meaningful statistical and interactive visualizations that can help users understand sales trends, product performance, regional performance, customer behavior, and relationships between numerical variables.

---

## 🎯 Project Objectives

The project aims to:

* Analyze sales performance across different products.
* Identify regional sales patterns.
* Examine sales trends over time.
* Analyze product price distributions.
* Study customer-level sales performance.
* Identify relationships between numerical variables.
* Create statistical visualizations using Seaborn.
* Create interactive visualizations using Plotly.
* Build a professional multi-chart dashboard.
* Provide meaningful business insights from the data.

## 📊 Visualizations

The project includes more than five different chart types.

### 1. Sales by Product

A bar chart comparing total sales generated by each product.

**Purpose:** Identify the strongest-performing products.

---

### 2. Daily Sales Trend

A line chart showing how sales change over time.

**Purpose:** Identify sales peaks, declines, and overall trends.

---

### 3. Price Distribution

A box plot showing the distribution of prices for each product.

**Purpose:** Compare median prices, variation, and potential outliers.

---

### 4. Sales Distribution by Region

A violin plot showing the distribution and density of sales across regions.

**Purpose:** Compare regional sales behavior.

---

### 5. Correlation Heatmap

A heatmap showing correlations between:

* Quantity
* Price
* Total Sales

**Purpose:** Identify relationships between numerical variables.

---

### 6. Regional Sales

A bar chart comparing total sales across different regions.

**Purpose:** Identify high-performing geographical segments.

---

### 7. Customer Sales Analysis

Customer-level analysis ranks customers according to their sales contribution.

**Purpose:** Identify high-value customers and understand purchasing behavior.

---

### 8. Interactive Plotly Charts

The project includes interactive charts with:

* Hover information
* Zoom
* Pan
* Interactive exploration
* Product filtering

---

### 9. Animated Visualization

An animated Plotly chart demonstrates changes in product-level sales across months.

**Purpose:** Provide a dynamic view of sales performance over time.

## ⚙️ Setup Instructions

### Step 1 — Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### Step 2 — Navigate to the project

```bash
cd Week6-Interactive-Sales-Dashboard
```

### Step 3 — Create a virtual environment

```bash
python -m venv .venv
```

### Step 4 — Activate the environment

#### Windows

```powershell
.venv\Scripts\Activate.ps1
```

#### Linux/macOS

```bash
source .venv/bin/activate
```

### Step 5 — Install dependencies

```bash
pip install -r requirements.txt
```

### Step 6 — Run the dashboard

```bash
python dashboard.py
```

Generated visualizations will be stored in:

```text
visualizations/
```

Responsible for:

* Loading CSV data
* Validating the dataset
* Preparing data types

Main functions:

```text

```

### Analysis Layer

Responsible for:

* KPI calculations
* Product aggregation
* Regional aggregation
* Customer analysis
* Correlation analysis

Main function:

```text
calculate_kpis()
```

### Visualization Layer

Responsible for generating static and interactive visualizations.

Examples:

```text

create_sales_trend_chart()
create_box_plot()
create_violin_plot()
```
